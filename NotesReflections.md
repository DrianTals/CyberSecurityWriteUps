# Key Insights

- Many beginner and medium Web Exploitation challenges can be solved by carefully inspecting the page structure and understanding how the web application behaves.
- Tools like browser developer tools, Burp Suite, and Kali Linux significantly speed up vulnerability discovery and testing.
- Reading the source code of a webpage often reveals hidden hints, comments, or parameters that can be exploited.
- Documenting writeups after solving challenges helps reinforce techniques and builds a personal knowledge base for future CTFs.

# Techniques That Clicked

- **Inspect Element (Browser DevTools)**  
  Used to analyze HTML elements, modify form inputs, and identify hidden fields that could be manipulated.

- **View Page Source**  
  Helpful for discovering hidden hints, comments, encoded strings, and JavaScript logic used by the challenge.

- **Decrypting ASCII Codes**  
  Converted encoded ASCII values into readable text to retrieve hidden flags or clues.

- **Burp Suite Interception**  
  Intercepted HTTP requests to modify parameters, test authentication bypasses, and analyze server responses.

- **Using Kali Linux Tools**  
  Leveraged Kali Linux environment for web testing, scripting, and analyzing vulnerabilities during challenges.
